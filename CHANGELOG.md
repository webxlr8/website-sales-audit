# Changelog

## 1.0.0 — 2026-10-13

First public release.

- Agent skill (`SKILL.md`) for auditing a live website and producing a client-ready, agency-branded PDF.
- Scripts: brand extraction, desktop and mobile crawl with automatic checks, contact sheets, annotated evidence screenshots, image annotation, and a report builder with overflow, font and preview checks.
- Configurable agency branding: name, logos, accent colours, contacts, stats and client logos.
- Audit checklist, writing style guide and report.json schema.
- Fictional demo store with a sample report.
