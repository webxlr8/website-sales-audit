What it checks

A conversion rate optimization (CRO) and UX checklist built from real e-commerce audits. Works with Shopify, WooCommerce, WordPress, Wix, Squarespace, Webflow and custom sites.

Checkout & payments

Stores that can't take payments, broken carts, missing policy pages.

Template leftovers

Theme demo text ("clothing items", "$150 free shipping", Lorem ipsum) on live pages.

Dark patterns & trust

Fake "people viewing" counters, fake stock warnings, no reviews, empty testimonials.

Mobile UX bugs

Chat buttons covering Add to Cart, cut-off prices, oversized banners.

Broken features

Wishlist 404s, popups cut off, blogs that don't open, tracking that doesn't track.

Findability

Titles, meta descriptions, H1s, page speed (LCP), analytics and pixel tags.

How it works

  1. Brand. Reads the client's fonts, colours, logo and product feed.
  2. Crawl. Screenshots every page on desktop and mobile with automatic checks.
  3. Verify. Claude reviews the pages, tests the buying journey and re-checks every finding.
  4. Report. Annotated evidence goes into a branded, print-ready PDF.

FAQ

Is it free?

Yes. It's MIT licensed and can be used for paid client audits.

Does it place orders or fill in forms?

No. Checkout is tested only up to the payment step. No personal or payment details are entered.

Can I white-label the report?

Yes. Set your agency name, logos, colours and contacts once in ~/.config/website-sales-audit/agency.json.

Is it an SEO audit tool?

It's a sales and conversion audit. It covers SEO basics (titles, meta descriptions, H1s, speed, tracking) but focuses on what stops visitors from buying.

Which AI does it need?

It's a Claude Agent Skill. The scripts are plain Python and Playwright, so other agents that read SKILL.md can use them too.
